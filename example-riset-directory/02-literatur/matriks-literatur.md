# Matriks Literatur

## Topik Penelitian
1. Klasifikasi penyakit tanaman berbasis citra digital (image classification)
2. Perbandingan performa arsitektur Deep Learning / CNN (Inception V3, VGG, ResNet, MobileNet)
3. Optimasi performa arsitektur model Inception V3 untuk ekstraksi fitur multi-skala
4. Analisis pengaruh variasi jumlah iterasi (epoch) terhadap akurasi dan konvergensi model
5. Evaluasi kestabilan model melalui kurva akurasi pelatihan (Train) dan validasi (Validation)
6. Pengukuran metrik performa klasifikasi menggunakan Confusion Matrix (Akurasi, TP, TN, FP, FN)
