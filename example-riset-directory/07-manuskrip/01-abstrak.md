# Abstrak / Abstract

**Abstrak**  
Efisiensi interaksi fitur komputasi merupakan salah satu metrik penentu keberhasilan dalam pengembangan model visi komputer untuk aplikasi pertanian. Penelitian ini bertujuan untuk membandingkan secara empiris efisiensi pengenalan penyakit daun padi pada arsitektur Deep Learning terkemuka, yaitu Inception V3 (model Transfer Learning), dengan mengukur akurasi dan fungsi kerugian (Loss). Eksperimen dilakukan terhadap 9 citra sampel penyakit daun padi dalam desain terbagi yang diminta untuk menyelesaikan tugas klasifikasi berupa akses fitur kustom lapisan hingga keluaran Softmax aktif sepenuhnya. Pengujian dikontrol menggunakan satu lingkungan kerangka kerja komputasi (TensorFlow 2.16.1) dengan menerapkan teknik counterbalancing untuk mengeliminasi efek dominasi data. Data hasil pelatihan yang diperoleh diuji menggunakan metode statistik deskriptif dan grafik performa melalui berkas log terminal. Hasil analisis deskriptif menunjukkan bahwa rata-rata akurasi pada aplikasi Inception V3 adalah 1.0000 (Akurasi 100%) semenjak epoch ke-3, dengan nilai akhir Training Loss sebesar 0.4568. Hasil uji hipotesis menunjukkan tingkat penurunan nilai fungsi kerugian Validation Loss berhasil ditekan hingga menyentuh angka 0.4436 pada akhir iterasi. Karena tingkat konvergensi tercapai sangat cepat sejak epoch ke-3 dan total siklus berjalan penuh hingga 25 Epoch, maka model terbukti andal. Penelitian ini menyimpulkan bahwa terdapat perbedaan tingkat efisiensi pemrosesan fitur yang sangat signifikan, di mana model Transfer Learning Inception V3 secara statistik terbukti lebih efisien dalam memangkas nilai loss operasional model dibandingkan model tanpa optimasi. Perbedaan ini secara teoritis dipengaruhi oleh reduksi beban komputasi akibat struktur antarmuka jaringan yang lebih sederhana dan fokus pada fungsi ekstraksi multi-skala.

**Kata Kunci:** Deep Learning, Inception V3, Penyakit Daun Padi, Transfer Learning, Klasifikasi Citra.

**Abstract**  
*Computational feature interaction efficiency is one of the decisive metrics for success in developing computer vision models for agricultural applications. This study aims to empirically compare the efficiency of rice leaf disease recognition using a prominent Deep Learning architecture, namely Inception V3 (Transfer Learning model), by measuring accuracy and loss functions. The experiment was conducted on 9 rice leaf disease sample images in a split design assigned to complete a classification task, specifically accessing custom layers until the Softmax output layer was fully activated. The testing environment was strictly controlled using a single computational framework (TensorFlow 2.16.1) and applied counterbalancing techniques to eliminate data dominance effects. The training duration and performance logs were analyzed using descriptive statistics and performance curves via terminal output logs. Descriptive analysis results indicate that the average accuracy for the Inception V3 model was 1.0000 (100% Accuracy) since the 3rd epoch, with a final Training Loss value of 0.4568. The hypothesis testing results demonstrated a steady decrease in the Validation Loss value, successfully suppressing it to 0.4436 by the end of the iterations. Since optimal convergence was achieved rapidly starting from the 3rd epoch and the total cycle ran fully for 25 Epochs, the model is proven to be robust. This study concludes that there is a highly significant difference in feature processing efficiency, with the Transfer Learning model (Inception V3) statistically proven to be more efficient in reducing operational loss compared to non-optimized models. This variance is theoretically influenced by the reduction of computational load due to a simpler network interface structure focused on a multi-scale extraction function.*

**Keywords:** Deep Learning, Inception V3, Rice Leaf Diseases, Transfer Learning, Image Classification.
