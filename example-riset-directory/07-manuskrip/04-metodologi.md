# 3. Metodologi Penelitian

## 3.1 Desain Penelitian dan Unit Analisis
Penelitian ini menggunakan pendekatan kuantitatif dengan metode eksperimen terkontrol (Controlled Experiment) menggunakan rancangan eksperimen terbagi (Within-Subject / Split Design). Desain ini dipilih untuk menguji hubungan kausalitas antara model arsitektur lapisan jaringan terhadap tingkat efisiensi performa akurasi model secara langsung, di mana seluruh subset citra menguji kedua kondisi konfigurasi bobot secara bergantian. Unit analisis dalam penelitian ini adalah dataset bersih citra penyakit daun padi (rice_leaf_diseases_cleaned) yang dikategorikan berdasarkan 3 jenis infeksi utama, yaitu Bacterial Leaf Blight, Brown Spot, dan Leaf Smut. Pengujian dilakukan langsung di lingkungan laboratorium simulasi komputasi Universitas Putra Bangsa (UPB) Kebumen untuk mensimulasikan kondisi pengolahan data riil. Dalam alur eksperimen ini, pemrosesan lapisan konvolusi dasar diposisikan sebagai baseline (kondisi dasar) yang mewakili arsitektur dengan kepadatan komputasi tinggi, sedangkan penambahan lapisan kustom Global Average Pooling dan Dropout bertindak sebagai intervensi yang menawarkan pendekatan desain jaringan yang minimalis untuk menyelesaikan tugas klasifikasi yang sama.

Untuk mengantisipasi munculnya efek pembelajaran (*learning effect*) yang dapat membiaskan pencatatan waktu, penelitian ini menerapkan teknik *counterbalancing*[cite: 1]. Urutan pengerjaan tugas dibedakan secara acak; sebagian responden memulai dari GoFood terlebih dahulu, sementara sebagian lainnya memulai dari GrabFood[cite: 1].

## 3.2 Variabel, Metrik, dan Instrumen Penelitian
Penelitian ini mengonfigurasi hubungan antarvariabel secara ketat untuk menjamin validitas hasil pengukuran. Variabel Independen (IV) dalam penelitian ini adalah Model Arsitektur Lapisan Jaringan, yang terdiri dari dua kategori, yaitu lapisan dasar Inception V3 prapelatihan ImageNet (base layers) dan lapisan klasifikasi kustom (top layers). Sementara itu, Variabel Dependen (DV) adalah Efisiensi Akurasi Model, yang dioperasionalisasikan secara terukur melalui nilai tingkat ketepatan klasifikasi dan minimalisasi fungsi kerugian. Untuk meminimalkan bias faktor teknis di luar arsitektur, penelitian ini menetapkan beberapa Variabel Kontrol seperti spesifikasi sistem komputer, versi kerangka kerja TensorFlow, nilai learning rate, dan ukuran dimensi citra. Metrik utama yang digunakan untuk mengukur Variabel Dependen adalah nilai capaian Accuracy dan fungsi kerugian Categorical Crossentropy dengan skala rasio antara 0.0 hingga 1.0. Pemilihan metrik ini merujuk pada standar baku evaluasi sistem cerdas, di mana stabilitas pergerakan kurva akurasi merupakan indikator paling objektif dan akurat untuk merepresentasikan efisiensi kerja jaringan. Instrumen pengumpulan data yang digunakan meliputi satu unit sistem komputer operasional, repositori skrip python pengeksekusi model, serta log terminal keluaran (verbose log). Data primer diperoleh secara langsung dari hasil eksekusi interaksi 9 citra sampel daun padi milik mahasiswa UPB Kebumen. Batasan awal perhitungan (epoch = 1) dimulai tepat saat fungsi model.fit() dieksekusi oleh sistem, dan pengumpulan data dihentikan (epoch = 25) tepat saat seluruh siklus iterasi selesai dijalankan secara penuh dan menyimpan hasil visualisasi grafik ke direktori output.

## 3.3 Skenario dan Prosedur Eksperimen
Skenario eksperimen dirancang secara tunggal dan spesifik untuk membandingkan performa klasifikasi kedua konfigurasi lapisan melalui perintah: "Lakukan proses pembaruan bobot dan ekstraksi fitur hingga model mencapai titik konvergen". Prosedur pelaksanaan eksperimen dijalankan secara runtut melalui beberapa tahapan terstandarisasi. Fase pertama adalah Persiapan Teknis, di mana peneliti menyiapkan berkas skrip kode python di dalam folder 05-kode/src/ serta memastikan jalur pemanggilan dataset mengarah tepat ke folder 04-data/. Sebelum pengujian dilakukan untuk setiap sesi perulangan, peneliti menerapkan Cold Start Protocol, yaitu melakukan pembersihan variabel memori cache sistem untuk memastikan pemrosesan arsitektur dimulai dari awal secara adil dari memori kosong. Fase kedua adalah Pemberian Instruksi, di mana dataset citra dikonfigurasi menggunakan fungsi pembagi otomatis validation_split=0.2 untuk memisahkan 80% data latih dan 20% data validasi tanpa disertai augmentasi eksternal guna mengukur kecepatan murni arsitektur dalam memetakan batas keputusan. Fase ketiga adalah Eksekusi dan Pengukuran, di mana sistem mengeksekusi kompilasi model dengan optimizer Adam pada learning rate 0.0001 dan dropout 0.3. Log terminal secara otomatis mencatat pergerakan nilai parameter ketepatan fungsi keputusan di setiap tahapan epoch berjalan. Fase terakhir adalah Pencatatan Data, di mana nilai parameter numerik akurasi dan loss direkam secara langsung dari objek history ke dalam berkas log teks untuk dipindahkan ke dalam basis data draf hasil analisis. Untuk memitigasi ancaman ketidakstabilan nilai akibat fluktuasi gradien ekstrim yang dapat merusak validitas internal, penelitian ini menerapkan teknik Counterbalancing penguncian nilai random seed sistem sehingga proses pembagian sampel bersifat konstan pada pengujian baseline maupun intervensi lapisan kustom.

## 3.4 Teknik Analisis Data
Data performa kuantitatif (Accuracy dan Loss) yang telah dikumpulkan dari 25 epoch perulangan dianalisis menggunakan statistik deskriptif dan analisis tren kurva melalui visualisasi komputasi Python. Alur analisis data dilakukan melalui tiga tahapan komputasi. Pertama, dilakukan Uji Asumsi Normalitas Gejala dengan memantau pola pergerakan kurva pembelajaran untuk memastikan tidak terjadi kondisi penyimpangan performa ekstrim. Asumsi kestabilan terpenuhi apabila nilai signifikansi garis grafik validasi bergerak selaras dan tidak memiliki celah renggang yang mengindikasikan gejala overfitting. Kedua, dilakukan Analisis Deskriptif untuk menghitung nilai pencapaian rata-rata (Mean Accuracy) dan nilai kerugian terendah untuk masing-masing subset data guna melihat visualisasi perbedaan awal performa kecepatan konvergensi sistem. Ketiga, dilakukan Uji Hipotesis Komparatif untuk mengevaluasi titik konvergensi pada tingkat kepercayaan penuh terhadap performa model kustom Inception V3. Kriteria pengambilan keputusan statistik diatur sebagai berikut: jika model mampu mencapai nilai akurasi mutlak 1.0000 secara teori dan empiris sejak iterasi awal serta menekan nilai Validation Loss di bawah ambang batas dasar, maka hipotesis alternatif (Ha) diterima, yang berarti modifikasi struktur lapisan atas efektif melindungi tingkat efisiensi pemrosesan tanpa memicu beban komputasi berlebih. Sebaliknya, jika model gagal mencapai kestabilan akurasi dan grafik bergerak fluktuatif, maka Hipotesis Nol (H0) diterima, yang berarti desain arsitektur kustom tidak memberikan dampak efisiensi nyata pada model.
